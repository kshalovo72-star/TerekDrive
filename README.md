# Терек Драйв

Брутальный Android-драйв-комбайн на Kotlin + Jetpack Compose.

## Что сейчас в проекте

- MapLibre Native + OpenFreeMap вместо 2ГИС;
- офлайн-пакет карты через MapLibre OfflineManager;
- 4 сезона и анимированный интерфейс;
- 10 анимированных тем спидометра;
- GPS-проверка скорости автомобиля;
- секундомер;
- гараж с 10 автомобилями;
- локальный музыкальный плеер: выбор аудиофайла с телефона;
- погода через Open-Meteo;
- настройки звука и анимаций;
- удалённый JSON-конфиг без изменения APK;
- GitHub Actions автоматически собирает debug APK после push.

## Карта

Используется OpenFreeMap со стилем Liberty на MapLibre. Данные карты основаны на OpenStreetMap. OpenFreeMap разрешает использование в приложениях и требует атрибуцию. Для офлайн-режима приложение создаёт отдельный offline region через MapLibre.

## Обновления

1. Удалённый контент/конфиг — меняется через remote-config.json без пересборки APK.
2. Новая версия кода — требует APK-сборки, но .github/workflows/android.yml запускает её автоматически через GitHub Actions.

## Важно

Для GPS-скорости пользователь должен дать приложению разрешение на геолокацию. Музыка берётся из файлов телефона.

Карта: OpenFreeMap / OpenStreetMap.
