# Терек Драйв

Android-навигация в брутальном тёмном стиле.

## Уже в MVP
- карта-макет и экран маршрута;
- 10 тем спидометра с анимацией;
- гараж с 10 автомобилями;
- быстрый старт навигации;
- тёмная тема и микроанимации.

## Запуск
Открыть проект в Android Studio и дождаться синхронизации Gradle.

Следующий этап: подключить OpenStreetMap/реальное GPS-позиционирование и сервис маршрутизации.
