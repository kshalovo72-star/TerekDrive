# Терек Драйв

Брутальный Android-навигатор на Kotlin + Jetpack Compose.

## Добавлено
- 2ГИС Full SDK 14.0.0;
- сезонные режимы: весна, лето, осень, зима;
- 2ГИС MapView с резервным экраном до установки ключа;
- заготовка под навигацию 2ГИС;
- брутальный тёмный интерфейс;
- 10 спидометров и 10 автомобилей в концепции приложения.

## Ключ 2ГИС
Для Mobile SDK нужен файл `dgissdk.key`. Бесплатные demo-ключи для Mobile SDK не подходят. Положите полученный ключ сюда:

`app/src/main/assets/dgissdk.key`

Файл исключён из Git через .gitignore.

Актуальная документация: https://docs.2gis.com/android/sdk/start
