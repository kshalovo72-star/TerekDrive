# Terek Drive — Unity graphics prototype

This branch is a visual prototype for the high-fidelity graphics layer.

## Target
- Unity + URP
- 3D cockpit / HUD
- emissive speedometer
- animated needle
- speed rings and telemetry
- particles for weather
- dark automotive lighting

Navigation/map integration stays separate until the visual prototype is approved.

Open the project at `unity/` and run `Assets/Scenes/Main.unity`.
