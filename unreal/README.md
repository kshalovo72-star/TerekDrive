# Terek Drive — Unreal Engine 5

High-fidelity mobile cockpit prototype.

Visual target:
- animated 0–300 km/h digital/analog speedometer
- neon needle, glow rings, glass and metal dashboard
- animated seasonal scenes: winter snow, spring petals, summer heat/light, autumn leaves
- premium startup cover
- adaptive Android quality profiles
- Mobile Deferred + HDR baseline for high-end devices

The repository contains the UE project source. Packaging an Android APK requires a local/CI Unreal Engine installation and Android toolchain; the GitHub connector cannot install Epic's proprietary engine or inject Epic credentials.
