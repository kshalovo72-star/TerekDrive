# Тerek Drive — Flutter engine

Новая реализация создаётся рядом со старым Kotlin/Compose клиентом.

Первый этап: Flutter shell, MapLibre/OpenFreeMap, GPS, спидометр, навигационный экран, Гена TTS и настройки.

Дальше: Nominatim + OSRM, офлайн-карты, голосовой ввод, погода, музыка, сезонные эффекты и Flutter Android CI.

Старый клиент не удаляется до завершения миграции.
